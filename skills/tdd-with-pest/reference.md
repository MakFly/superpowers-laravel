# Pest TDD Reference

## RED-GREEN-REFACTOR
- RED: smallest failing behavior test
- GREEN: minimal pass
- REFACTOR: cleanup with green tests maintained

## Useful patterns
- dataset-driven edge cases
- expressive custom expectations
- factory states for setup clarity

## Commands
- `./vendor/bin/pest tests/Feature/...`
- `./vendor/bin/pest --filter="..."`
- `./vendor/bin/pest`
